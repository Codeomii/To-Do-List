**TaskSpace 3D** is a high-performance, visually immersive To-Do web application built using modern Web Technologies (HTML5, CSS3, and Pure JavaScript). Featuring a dark-mode 3D glassmorphism interface, interactive analytics, priority tagging, and real-time state filtering, it elevates daily task management into an engaging visual experience.

---

## ✨ Key Features

- **🎨 3D Dark Glassmorphism UI**: High-contrast dark theme with glowing neon accents, soft dynamic shadows, and smooth depth interactions.
- **📊 Dynamic Analytics Tracker**: Live visual completion progress bar alongside real-time task counters (**Total**, **Pending**, and **Done**).
- **🏷️ Priority Tagging System**: Assign priority levels (*High*, *Medium*, *Low*) to organize workflow impact.
- **🔍 Instant Search & Filter**: Filter tasks on-the-fly using state tabs (*All*, *Active*, *Done*) and real-time title search.
- **💾 LocalStorage Integration**: Persistent task saving ensures your data survives browser refreshes and session restarts.
- **⚡ Lightweight & Fast**: Built with pure Vanilla JS — zero external framework dependencies for instant loading speed.

---

## 🛠️ Tech Stack & Concepts Used

| Technology | Implementation Details |
| :--- | :--- |
| **HTML5** | Semantic tags structuring application cards, status dashboards, and input bars. |
| **CSS3** | Custom variables, Flexbox layout, `backdrop-filter` glassmorphism, 3D perspective transforms, and hover keyframe animations. |
| **JavaScript (ES6+)** | Dynamic DOM manipulation, state array filtering, Event Listeners, and browser `localStorage` management. |
